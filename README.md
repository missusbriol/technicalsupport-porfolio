Technical Customer Support Portfolio
A modern, responsive portfolio website highlighting technical support capabilities, L2/L3 support experience, QA methodology, and software development background.

🔗 Live Demo: macasandra-briol-porfolio.vercel.app

🛠️ Tech Stack
Framework: Angular

Language: TypeScript

Styling: SCSS

AI Assistance: ChatGPT & Claude Code

Deployment: Vercel


✨ Features
Interactive Support Workflow: Visual breakdown of troubleshooting and escalation steps.
Toolkit Showcase: Clear display of tools and platforms used (Microsoft 365, BMC, ServiceDesk, etc.).
Experience Roadmap: Direct mapping of background across QA, L2/L3 support, and software development.
Resume Download: Built-in PDF resume access.
Dark / Light Mode: Theme toggle for customizable viewing.

🚀 Local Development Setup
Prerequisites
Ensure you have Node.js installed along with the Angular CLI.

Bash
npm install -g @angular/cli

Installation
Clone the repository:
Bash
git clone https://github.com/missusbriol/technicalsupport-porfolio.git
cd technicalsupport-porfolio

Install dependencies:
Bash
npm install

Run the development server:
Bash
ng serve

Open your browser and navigate to http://localhost:4200/.
